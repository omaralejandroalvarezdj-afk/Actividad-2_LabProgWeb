# Actividad-2_LabProgWeb

-Objetivo-

Desarrollar un sitio web responsivo, semántico y accesible, utilizando HTML5 para organizar el contenido y CSS3 para darle diseño. También se busca que la página pueda visualizarse correctamente desde una computadora o un dispositivo móvil.

-Tecnologías utilizadas-

HTML5: Se utilizó para crear la estructura y el contenido de la página.

CSS3: Se utilizó para los colores, tamaños, imágenes y estilos.

Flexbox: Se utilizó para organizar algunos elementos de la navegación y del diseño.

CSS Grid: Se utilizó para acomodar los productos y la sección de contacto.

Media Queries: Se utilizaron para adaptar la página a pantallas pequeñas.

Visual Studio Code: Editor utilizado para trabajar con los archivos.

GitHub: Plataforma utilizada para almacenar el código.

GitHub Pages: Servicio utilizado para publicar la página en Internet.
